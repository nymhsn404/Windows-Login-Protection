Security Notes
This utility is a small workstation protection layer, not a replacement for Windows Account Lockout Policy, Microsoft Defender/EDR, MFA, BitLocker, firewall controls, SIEM monitoring, or backups.
The script processes Security Event ID 4625 only for:
Logon Type 2 — Interactive
Logon Type 10 — Remote Interactive / RDP
Test automatic shutdown on a non-critical PC before production use.
